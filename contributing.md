# Contribution Guidelines

Please note that this project is released with a
[Contributor Code of Conduct](https://github.com/sindresorhus/awesome/blob/main/code-of-conduct.md).
By participating in this project you agree to abide by its terms.

## Adding a project

- The project must be related to IKEA Home smart: the TRÅDFRI gateway, the
  DIRIGERA hub or the IKEA smart home devices that work with them.
- Add it to the section that fits best, keeping one list item per line.
- Use the format `- [owner/repo](https://github.com/owner/repo) - Description.`
- Keep the description short, start with a capital letter and end with a
  period.
- Append 📦 to the description if the project is archived or unmaintained.
- Run `npx awesome-lint` and `npx markdownlint-cli2 "**/*.md"` before opening
  a pull request.
